=== 3. Video code ===
Corrected line:
<video src="../media/intro.mp4" controls preload="metadata"></video>

- Starting point of the relative path:
  The path starts from the folder of the file that contains the code, which is the pages folder
  (pages/courses.html). The media folder is next to index.html, not inside pages, so the path
  must go up one folder first: src="../media/intro.mp4". The original "media/intro.mp4" makes the
  browser look for pages/media/intro.mp4, which does not exist.

- muted="false":
  muted is a boolean attribute. If it is written at all, the video is muted, whatever value it has.
  So muted="false" still mutes the sound. I removed the muted attribute completely so the visitor
  hears the sound when pressing play.

- preload value:
  preload="metadata" - the browser downloads only the metadata (such as duration and size)
  before playback, not the whole video.
