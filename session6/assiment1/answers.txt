=== Selector for a full course's status ===
.course-card[data-status="full"] .status

It matches the <span class="status"> element that is inside an <article class="course-card">
whose data-status attribute is exactly "full". It does not match the <article> itself or the <p> description,
so only the status gets the gray background. On the page now it matches the «اكتمل العدد» span in the CSS Foundations card.
